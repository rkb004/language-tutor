# Example dialogue (illustrative)

**Scenario:** Talking to a family member

**Tutor:** Namaskaram! Ela unnaru?  
*Hello! How are you?*

**Learner:** Nenu bagunnanu. Meeru ela unnaru?  
*I'm well. How are you?*

**Tutor:** Nenu kuda baagunnanu!  
*I'm well too!*

**Practice note:** Try asking what someone ate today: `Meeru ivala emi tinnaru?`

> This is a hand-written sample of the intended user experience, not generated by a deployed model.
